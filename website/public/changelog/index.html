Changelog

What changed in Principia, newest first · All releases on GitHub

October 2026

Mac preview download

Download Principia for Apple Silicon Macs from useprincipia.com. It is an early, unsigned preview: macOS asks you to confirm the first open, and Principia tells you when a new version is out.

Token activity

Usage counts every token across Claude Code, Codex and Principia’s own agents, once each, in a year-long activity grid with your streaks, peak day and longest task.

Sounds only for what matters

Three short sounds: Done, Needs you, Problem. Quiet for routine work, and never for the thing you are already looking at.

Connect once, use everywhere

One connection per service, by API key, sign-in or MCP. Dashboards, agents, Knowledge and Autopilot all see it, and anywhere it is missing offers Connect right there.

Autopilot routines

Agents pick up the next task on their own, as many at once as you allow. Ready-made routines like a morning brief and a weekly review, and a chief of staff that suggests what is next.

Phone pairing

Pair your phone with a QR code and use your company from it: chats, approvals, sessions and the board. The iPhone app is coming to TestFlight.

Worktree per task

Starting a code task opens its own git worktree and branch, with an agent on it. The task follows the work until the PR merges.

The company browser

Every company has its own browser beside the chat. Agents drive it while you watch, and Take over hands you the wheel.

Diagrams

Agents answer with real, interactive diagrams wherever you read them.
