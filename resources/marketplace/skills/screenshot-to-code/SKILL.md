# Screenshot to code

1. Look at the image carefully: layout grid, spacing scale, type sizes and weights, colors, states.
2. Find the project's existing components, tokens and styling approach; reuse them instead of inventing new ones.
3. Build the screen, then compare against the image section by section and fix differences.
4. If the app can be run, take a screenshot of your result and compare it side by side with the original.

Report anything you could not match (missing fonts, icons, data) instead of guessing silently.
